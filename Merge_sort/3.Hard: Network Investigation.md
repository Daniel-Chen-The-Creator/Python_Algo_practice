Problem 3: Network Investigation

Difficulty: Hard

Problem Description

A campus network team records the response times of \(N\) network requests in chronological order.

The response time of request \(i\) is \(D_i\) milliseconds.

The team calls a pair of requests \((i,j)\) a significant improvement pair if both of the following conditions hold:

Request \(i\) occurred before request \(j\), meaning \(i<j\).
The response time of request \(i\) is strictly greater than twice the response time of request \(j\), meaning \(D_i>2D_j\).

Determine the total number of significant improvement pairs.

The requests in a pair do not need to be consecutive. A request may belong to more than one pair.

Input Specification

The first line contains an integer \(N\), the number of requests.

The second line contains \(N\) space-separated integers \(D_1,D_2,\ldots,D_N\), given in chronological order.

The following constraints apply:

$$ 1 \le N \le 200\,000 $$ $$ 1 \le D_i \le 10^9 $$
Output Specification

Output one integer: the number of significant improvement pairs.

Sample Input
5
8 3 5 2 1
Sample Output
6
Explanation of Sample Output

The six significant improvement pairs are:

Request Indices \((i,j)\)	Comparison
\((1,2)\)	\(8 > 2 \times 3\)
\((1,4)\)	\(8 > 2 \times 2\)
\((1,5)\)	\(8 > 2 \times 1\)
\((2,5)\)	\(3 > 2 \times 1\)
\((3,4)\)	\(5 > 2 \times 2\)
\((3,5)\)	\(5 > 2 \times 1\)

Requests 4 and 5 do not form a significant improvement pair because:

$$ 2 = 2 \times 1 $$

The comparison must be strictly greater.

Scoring
Percentage of Marks	Additional Constraints
20%	\(N \le 100\)
30%	\(N \le 5\,000\)
50%	No additional constraints.

Note: The original chronological order is part of the definition of a valid pair. The answer may exceed the range of a signed 32-bit integer.
