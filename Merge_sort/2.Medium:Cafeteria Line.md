Problem 2: Cafeteria Line

Difficulty: Medium

Problem Description

A cafeteria assigns each order a unique number from \(1\) to \(N\). Students should line up in increasing order of their order numbers.

However, the current order of the students in the line is:

$$ A_1,A_2,\ldots,A_N $$

A staff member can rearrange the line by repeatedly asking two adjacent students to swap positions.

Determine the minimum number of adjacent swaps needed to arrange the students in increasing order of their order numbers.

Input Specification

The first line contains an integer \(N\), the number of students.

The second line contains \(N\) space-separated integers \(A_1,A_2,\ldots,A_N\), representing the students’ order numbers from the front of the line to the back.

Each integer from \(1\) to \(N\) appears exactly once.

The following constraint applies:

$$ 1 \le N \le 200\,000 $$
Output Specification

Output one integer: the minimum number of adjacent swaps required.

Sample Input
5
4 1 3 2 5
Sample Output
4
Explanation of Sample Output

One optimal sequence of swaps is:

4 1 3 2 5
1 4 3 2 5
1 3 4 2 5
1 3 2 4 5
1 2 3 4 5

Each step swaps two adjacent students.

This requires four swaps, and it is impossible to arrange the line using fewer swaps.

Scoring
Percentage of Marks	Additional Constraints
25%	\(N \le 100\)
25%	\(N \le 5\,000\)
50%	No additional constraints.

Note: The answer may exceed the range of a signed 32-bit integer. Python integers can store the answer directly.
