Counting Rule

Each execution of the following right-shift operation counts as one move:

nums[j + 1] = nums[j]

Placing key in its final position does not count as a move.

Example

moves = insertion_sort_count(nums)

print(nums)   # [1, 2, 3]
print(moves)  # 2
